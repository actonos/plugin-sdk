# Figma SaaS Connector & Tools Plugin

ActonOS SaaS Connector and Agent Tools integration for Figma design workspaces.

## Actions / Agent Tools
- `get_file`: Retrieve Figma node tree and file metadata
- `get_comments`: Fetch design feedback threads
- `post_comment`: Pin comments/feedback onto canvas coordinates

## Permissions
- `net_outbound`: `["api.figma.com"]`
- `secrets`: `["figma_access_token"]`

# Notion SaaS Connector & Tools Plugin

ActonOS SaaS Connector and Agent Tools integration for Notion workspaces.

## Actions / Agent Tools
- `search_pages`: Search pages and databases across workspace
- `create_page`: Create a new page under a parent page or database
- `query_database`: Query rows/entries in a Notion database
- `append_block_children`: Append rich text paragraph blocks to a page

## Permissions
- `net_outbound`: `["api.notion.com"]`
- `secrets`: `["notion_api_key"]`

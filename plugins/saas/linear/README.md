# Linear SaaS Connector & Tools Plugin

ActonOS SaaS Connector and Agent Tools integration for Linear project tracking.

## Actions / Agent Tools
- `list_issues`: List issues and tasks
- `create_issue`: Create new issues with team, title, priority, description
- `update_issue_status`: Update issue workflow states

## Permissions
- `net_outbound`: `["api.linear.app"]`
- `secrets`: `["linear_api_key"]`

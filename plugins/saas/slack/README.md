# Slack SaaS Connector & Tools Plugin

ActonOS SaaS Connector and Agent Tools integration for Slack.

## Actions / Agent Tools
- `post_message`: Post messages and reports to Slack channels
- `list_channels`: Discover public and private channels
- `get_history`: Retrieve recent channel message history

## Permissions
- `net_outbound`: `["slack.com"]`
- `secrets`: `["slack_bot_token"]`
